# Distributed File Sharing

A decentralized file sharing system that enables secure, fast, and reliable transfer of data across distributed nodes.  
Built with fault tolerance, scalability, and redundancy, it allows seamless peer-to-peer sharing without relying on a central server.

## Features
- Peer-to-peer file transfer
- Secure and encrypted communication
- Fault tolerance and redundancy
- Scalable across multiple nodes
